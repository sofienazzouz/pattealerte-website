# PatteAlerte website

Static website draft for GitHub Pages. No build step is required. The privacy policy is a draft and must be confirmed against the released app and publisher contact details before publication.

## Local preview

Open `index.html` in a browser. The privacy page is at `privacy/`.

## GitHub Pages

After the repository is created, enable Pages from the `main` branch and repository root. Add the custom domain only after confirming DNS control for `pattealerte.com`.
